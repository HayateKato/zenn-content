# 日本語文章レビュー

渡された文章を以下の観点で評価してください。
修正する場合は、どこをどのように修正したのかがわかるようにしてください（修正前と修正後を並べる、または修正箇所と理由を明記する）。

## 評価の観点

- すべての文の主語、目的語、修飾語を明らかにする。
- 口語的な言い回しを避ける。
- 正しく、自然な日本語を使う。
- 同じ意味ならば同じ言葉で、異なる意味ならば異なる言葉で書く。
- すべての用語は、きちんと定義してから使われているか。
- 時制は適切か。
    - 技術記事で、現在の構成や状態を説明する文は「〜ています」で書かれているか。（例：「〜を公開するために使用しています。」）
    - 技術記事で、その構成を選んだ理由や経緯を説明する文は「〜ました」で書かれているか。（例：「〜と考え、採用しました。」）
    - 1つの文の中で、過去の判断（「〜と考え」など）と現在の状態（「〜ています」）が混ざっていないか。

## 進め方

1. 対象の文章（記事ファイルや貼り付けられた文章）を読む。
2. 上の観点ごとに問題のある箇所を挙げ、修正前・修正後・理由を示す。
3. 問題がない観点は、問題がないと簡潔に伝える。
4. ファイルの修正を頼まれた場合は、修正内容をファイルに反映し、変更した箇所をまとめて伝える。
